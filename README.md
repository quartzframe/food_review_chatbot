# FoodieBot - Food Review Chatbot

A beginner-friendly food review chatbot built with Python Flask.

## Included
- Python Flask backend
- HTML/CSS/JavaScript frontend
- Food ratings and reviews
- Quick food buttons
- Responsive chatbot UI
- Gunicorn for deployment
- Environment file template

## Run
Install dependencies from requirements.txt and run app.py.

The default local address is http://127.0.0.1:5000

## Add more foods
Edit the FOOD_REVIEWS dictionary in app.py.
